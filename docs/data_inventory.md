# 使用データ一覧

本プロジェクト「武蔵野市における公共交通アクセスと都市構造の空間分析」で使用したデータ、加工方法および保存先を示す。

距離・面積分析には **EPSG:6677（JGD2011 / 平面直角座標系第IX系、単位：m）** を使用した。以下の「対象年・時点」は統計・地物の基準時点を示し、ダウンロード日とは区別する。CSVなどの属性表自体には座標参照系はない。

## 3. 前処理・採用条件

### 行政区域・鉄道・駅

- 行政区域から武蔵野市を抽出し、市境から1.5kmの周辺範囲を作成した。
- 市外駅も対象とするため、この周辺範囲を用いて駅・鉄道路線を準備した。
- 駅データから作成した代表点を用いて距離を計算し、半径800mのバッファを作成した。重複部分を統合したバッファも保存した。

### 人口・駅アクセス

- 人口属性表と500mメッシュ境界を、文字列に統一したメッシュコードで結合した。
- 総人口を数値型の `population` 列に保存した。
- 対象は武蔵野市と交差する **69メッシュ**。距離計算の代表点には、市境でクリップする前の完全メッシュの中心点を使用した。
- 最寄駅代表点までの直線距離が **800mを超え**、人口が **4,420人以上（対象69メッシュのP75として採用）** のメッシュを候補とした。800mちょうどは圏内とする。
- 完全に市内にある候補を主要候補、市境をまたぐ候補を参考候補とした。抽出結果は主要候補4件・参考候補2件。

### 土地利用

- 完全500mメッシュと100m土地利用メッシュをIntersectionで交差処理した。
- 交差片の面積を集計し、完全500mメッシュの面積を分母として建物用地割合を算出した。
- 分子と分母の面積計算方法をそろえ、交差片の面積合計と元メッシュ面積の整合性を確認した。
- 市境でクリップしたレイヤーは表示用とし、面積割合の集計単位と区別した。
- 「建物用地」は土地利用分類であり、住宅専用の面積割合や建物の建築面積・延床面積を示さない。

### 人流

- 2019年10月・平日昼間を対象とした。保存済み属性表の抽出条件は `year = 2019`、`month = 10`、`dayflag = 1`、`timezone = 0`。
- `mesh1kmid` と1kmメッシュ境界のメッシュコードを結合した。
- 推計滞在人口は月内の該当区分における平均的な滞在人口として扱い、1か月の延べ人数や鉄道乗降者数とは区別した。
- 500m候補への人口配分は行わず、候補を含む1kmメッシュ全体の値として参照した。主要候補4件は2つの1kmメッシュに含まれるため、人流の比較単位は2区画である。

## 5. 解釈・再利用上の注意

1. **対象年が異なる。** 人流2019年、人口2020年、土地利用2021年、バス停留所・バスルート2022年、行政区域2023年、鉄道・駅2025年を組み合わせている。同一時点の都市状況の再現や、時系列変化・因果関係の検証を目的としない。
2. **距離は直線距離である。** 道路、踏切、駅出入口、バス路線・運行頻度を考慮していない。800mを実際の徒歩10分や公共交通空白地域の判定基準と解釈しない。
3. **クリップしても人口値は按分されない。** 市境の500m・1kmメッシュは、市外部分を含む元メッシュ全体の値を保持する。表示用メッシュの値の合計を武蔵野市の総人口・滞在人口としない。
4. **解像度と指標が異なる。** 居住人口500m、土地利用100m、人流1kmを使用している。居住人口と推計滞在人口の直接差分や、1kmの値を500m候補の値とみなす比較は行わない。
5. **測地系と投影法を区別する。** 元データのCRSは付属の定義情報で確認し、必要な座標変換を行う。EPSG:6677は分析用CRSであり、全ての配布データの元CRSを意味しない。
6. **出典と利用条件を引き継ぐ。** 加工済みデータの再利用・再配布時にも各提供元の利用条件を確認し、出典および加工した旨を記載する。
